# Gator - Blog Aggregator CLI

Gator is a command-line RSS feed aggregator built with TypeScript and PostgreSQL.

It allows users to register, add RSS feeds, follow feeds, collect posts from feeds, and browse the latest posts.

## Requirements

Before running Gator, make sure you have:

- Node.js installed
- PostgreSQL installed and running
- npm installed

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/blog_aggregator.git
